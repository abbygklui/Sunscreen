# Sunscreen

A friendly, modern mobile app that reminds you to wear and reapply sunscreen.

## Features

- **Morning UV Alert** — Get a push notification when today's UV index is high, so you remember to apply sunscreen before heading out.
- **Reapplication Timer** — Tap "I applied sunscreen!" to start a countdown. Get notified when it's time to reapply (default: every 2 hours, configurable).

## Tech Stack

- **Flutter** (Dart) — cross-platform, Android-first
- **Riverpod** — state management
- **Open-Meteo API** — free UV index forecasts (no API key needed)
- **Material 3** — modern, warm, friendly design
